# pfBlockerNG Custom IPv4 Feeds

These files contain the custom IPv4 block lists used by pfBlockerNG. Each feed contains one IPv4 address per line, with no headers or comments.

The individual feeds are intended to be added as separate Source Definitions inside one consolidated pfBlockerNG IPv4 group.
